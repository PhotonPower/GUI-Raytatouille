# ADR 0004: raytatouille ist keine harte Abhängigkeit

**Status:** angenommen (2026-10-07)

## Entscheidung

`raytatouille` steht nicht in `dependencies` von `pyproject.toml`. Es wird aus dem Quellcode gebaut
(C++, nanobind) und liegt nicht auf PyPI. Eine Abhängigkeit nach Namen würde pip auf ein
gleichnamiges Fremdpaket zeigen lassen. Es gibt den Extra `lib` mit einer Git-URL und eine
Fehlermeldung mit Hinweis, wenn der Import fehlt.

## Folgen

`pip install rtt-explorer` allein reicht nicht, die Installationsanleitung beschreibt beide
Schritte. Sobald die Bibliothek Wheels veröffentlicht, wird sie reguläre Abhängigkeit.
