# ADR 0001: Streamlit als Explorer neben der geplanten PySide6-GUI

**Status:** angenommen (2026-10-07)

## Kontext

[ADR 0012 der Bibliothek](https://github.com/PhotonPower/Raytatouille/blob/main/docs/adr/0012.md)
legt für M10 eine Desktop-GUI mit PySide6 und pyvista fest und nennt eine Web-GUI als verworfen.
Zum Ausprobieren der Python-API und zum Finden von Lücken (siehe `docs/feedback/gui-anforderungen.md`
der Bibliothek) wird früher ein schnelles Werkzeug gebraucht.

## Entscheidung

Der Explorer ist eine Streamlit-Anwendung in einem eigenen Repository. Er ist ein Erkundungs- und
Testwerkzeug und ersetzt die M10-GUI nicht. Streamlit erlaubt Tabellen, Diagramme und Widgets mit
wenig Code und läuft mit `AppTest` ohne Browser in Tests.

## Verworfen

Sofort PySide6: zu aufwendig für den Zweck, Lücken der API zu finden.
Ein Ordner im Repo der Bibliothek: vermischt Build (C++) und GUI-Abhängigkeiten.

## Folgen

Streamlit rechnet bei jeder Eingabe neu, ein Modell mit Undo und Skriptausgabe (G3) ist hier nicht
sinnvoll. Erkenntnisse fließen als Aufträge in die Bibliothek.
